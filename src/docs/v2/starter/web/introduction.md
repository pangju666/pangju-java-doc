# Web

## 概述
这个模块我集成了`spring-boot-starter-webmvc`、[`Pangju Framework Starter Jackson`](/v2/starter/json/introduction)和[`Pangju Framework Web`](/v2/framework/web/introduction)。

## 依赖

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-webmvc</artifactId>
</dependency>
<dependency>
    <groupId>io.github.pangju666.framework.boot</groupId>
    <artifactId>framework-starter-jackson</artifactId>
</dependency>

<dependency>
    <groupId>io.github.pangju666.framework</groupId>
    <artifactId>framework-web</artifactId>
</dependency>
```

## 引入
```xml
<dependency>
    <dependency>
        <groupId>io.github.pangju666.framework.boot</groupId>
		<artifactId>framework-starter-web</artifactId>
    </dependency>
</dependency>
```
